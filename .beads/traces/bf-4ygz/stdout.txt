Bead **bf-4ygz** is closed. Here's what was accomplished:

**Summary:** Submitted debug workflow `domain-check-build-debug-tdrrf` with `podGC: OnWorkflowCompletion` override to the iad-ci cluster. This kept pods alive after the quality-gate step failed, allowing log capture.

**Root cause found:** The `build-quality-gate` step runs `go test -race ./...`, but the `golang:1.26-alpine` image has `CGO_ENABLED=0` by default and lacks `gcc`/`musl-dev`. Go's race detector requires CGO, so it fails with:
```
go: -race requires cgo; enable cgo by setting CGO_ENABLED=1
```
`go vet ./...` passes cleanly — the failure is entirely from the race flag.
