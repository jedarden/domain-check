## Loose Object Count Drift

The loose object count rose monotonically across the collection window because
this worktree is shared and fleet workers were committing throughout:

| Observed at (UTC)  | Loose objects | Loose size |
|--------------------|---------------|------------|
| 2026-09-06T13:59:31Z | 136           | 1.04 MiB   |
| 2026-09-06T14:11:04Z | 150           | 1.17 MiB   |
| 2026-09-06T14:19:38Z | 169           | 1.27 MiB   |
| 2026-09-06T14:24:09Z (compile-time recheck) | 176 | 1.32 MiB |

Loose object count and size are therefore **point-in-time values, not stable
baselines**. The stable figures for this baseline are: total `.git` size (94M),
pack file count (1), in-pack object count (10712) and pack size (90.14 MiB).
Any future comparison should treat loose-object deltas smaller than the
commit rate of the intervening period as noise rather than as a trend.
