EXIT CODE ANALYSIS
-----------------
Exit code: 2 (from `set -ex` causing the script to exit on the failing command)
Failing step: go test -race ./...
Specific error: "go: -race requires cgo; enable cgo by setting CGO_ENABLED=1"
Root cause: Alpine Linux (golang:1.26-alpine) lacks gcc/musl-dev needed for CGO.
            The Go race detector requires CGO (it links against a C runtime).

go vet ./... passed successfully (no output = no issues).
Only go test -race ./... failed due to missing CGO toolchain.

Fix options:
  1. Switch image from golang:1.26-alpine to golang:1.26 (Debian-based) —
     glibc + gcc available out of the box, CGO works natively.
  2. Stay on alpine but add `apk add gcc musl-dev` and set CGO_ENABLED=1.
  3. Remove `-race` flag (not recommended — race detection is valuable).
