Quality-Gate Step (from WorkflowTemplate)
-----------------------------------------
The build-quality-gate template runs inside a kaniko-like Alpine container:
  1. apk --no-cache add git ca-certificates
  2. git clone the branch/tag
  3. go vet ./...
  4. go test -race ./...

Root Cause
----------
go test -race requires CGO (it needs the race detector runtime, which is a C library).
Alpine sets CGO_ENABLED=0 by default (no C compiler/toolchain).
This causes go test -race to fail with exit code 2.

This failure is consistent across ALL recent domain-check-build runs:

  ...and earlier runs

Fix Required
------------
Either:
  a) Use a non-Alpine base image for the quality-gate step (e.g., debian-slim or ubuntu),
     or install build-base (gcc, musl-dev) on Alpine and set CGO_ENABLED=1.
  b) Drop the -race flag from go test (loses race detection in CI).
  c) Use a dedicated test stage on a golang:debian image (separate from the kaniko build).

Option (a) is preferred: install build-base in Alpine and set CGO_ENABLED=1:
  apk add --no-cache git ca-certificates build-base
  export CGO_ENABLED=1
